## 官方预设计划（6 套）

预设计划在“账号”页默认关闭；拨开开关即按推荐参数拷贝生成独立副本启用：

| 预设计划 | 默认时间 | 包含任务与预设要点 |
| --- | --- | --- |
| 早间日常巡检 | 每天 07:30 | 每日日常全清 → 结界寄养与寮管理 → 探索突破与道馆 |
| 午间寄养与斗技 | 每天 12:15 | 结界寄养与寮管理 → 斗技与协同斗技（预设单人斗技 5 场） |
| 晚间逢魔与寮活动 | 每天 18:30 | 逢魔之时与首领退治 → 寮限时活动全集 |
| 夜间御魂刷本 | 每天 21:30 | 副本刷取（预设御魂魂土 30 局）→ 每日日常全清 |
| 双号组队刷御魂 | 每天 22:15 | 副本刷取（预设双人私密队队长 30 局，自动唤醒协战小号） |
| 周末道馆阴界与协同 | 周六日 19:30 | 寮限时活动全集 → 斗技与协同斗技（预设协同斗技队长 10 场） |

## 安全与资产保护

- **不碰付费按钮**：商店礼包只识别免费“领取”按钮，带勾玉或魂玉标价的商品一律跳过；花合战三选一礼盒默认不代选，未设置时会停下交由玩家处理。
- **未知弹窗即停**：遇到未收录的新活动弹窗、验证码或界面异常时立即暂停并上报，绝不盲点屏幕。
