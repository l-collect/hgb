计划属于一个游戏账号，由服务端按你在“我的”里设定的时区统一计时。

## 预设计划与独立配置副本

每个游戏的任务包都带有一组官方**预设计划**（如早间日常、午间寄养斗技、晚间逢魔、夜间御魂等），直接列在账号的定时计划列表中，**默认处于关闭状态**：

1. **直接启用**：拨开某个预设计划右侧的开关，若此前未单独改过配置，系统会自动将**任务库中各任务的默认配置**（叠加该预设推荐的参数微调与触发时间）深拷贝一份，生成专属于该计划的配置副本并立即启用。
2. **计划间互不干扰**：启用后点进计划详情页（再点任意已选任务的“配置”），修改的只是**当前这一个计划所持有的配置副本**。例如同一个账号同时启用“午间单人斗技（5 场）”和“周末协同斗技（10 场）”，两份计划各自保存独立的斗技参数，互不覆盖，也不会改动你在“任务”页手动单次运行时的配置。
3. **重置与自定义**：预设计划随时可在详情页重置回默认配置并关闭；也可以点右上角“新建计划”自由组合任务顺序与时间。

## 调度与时间窗口

- **随机浮动（±分钟）**：在设定时间前后随机偏移若干分钟触发，避免每天固定整点机械上线。设为 `0` 则准点触发。
- **最晚开始时间**：到点后若目标设备正忙或离线，服务端会持续等待，直到超过最晚开始窗口（默认 30 分钟）才记为“跳过”；打开通知里的“计划没执行”规则会收到提醒。
- **运行设备与协战账号**：不勾选设备时，自动分配给任意已安装该游戏的在线设备；组队类计划可指定最多 2 个协战小号，未指定时沿用账号默认协战搭子。

## 到点后的设备分配顺序

1. 优先排进当前已登录该游戏账号的在线应用队列；
2. 否则分配给空闲、支持自动切号且未占用其他默认账号的应用，先切号再执行；
3. 在计划详情页点**立即运行**可按相同规则马上跑一轮，不影响下一次定时触发。
