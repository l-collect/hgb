游戏账号是护肝宝管理配置与调度的核心单元：单跑配置、定时计划、协战关系和战报记录都绑定在游戏账号上，与具体哪台手机解耦。护肝宝只记录你起的名字、游戏昵称与编号（UID），不收集游戏密码。

## 读取设备登录自动建号

阴阳师无需手动填写新建账号表单：

1. 在已开启 Magisk Root 权限的手机上打开阴阳师并登录目标角色，确保护肝宝在 **Magisk → 超级用户** 中已开启授权。
2. 手机端连上云端时会自动读取本机分区配置（`clientconfig`）与登录会话（`MPay / UniSDK`），也可在手机或 Web 控制台的「账号与计划」页点击 **读取设备登录**。
3. 云端按角色 `UID` 自动创建或更新对应的游戏账号（含同一通行证下的多个区服角色），自动绑定当前设备，并使用 AES-GCM 加密保存每个角色的专属登录快照。

## 云端下发登录与多号切号

- **手动一键下发**：在「账号与计划」或「账号设置 → 登录快照」中点击 **下发到设备**，即可将该角色加密保存的分区与登录信息原子写回目标在线手机（自动停止游戏进程、无损保留目标手机画质与补丁配置、切换目标区服 `areaSetId` 并修复文件属主权限）。
- **作业自动切号**：当某台设备需要执行另一个账号的计划或作业时，若目标账号存有云端登录快照，设备会自动拉取快照切换至对应区服角色执行，并在跑完后按需切回默认常驻账号。

## 默认协战搭子

同一游戏下添加 2 个及以上账号后，可在账号设置里绑定 **1 号 / 2 号协战小号**：

- 当主号运行双人或三人组队刷本（御魂、觉醒、业原火、永生之海等）或周末协同斗技时，服务端会自动唤醒空闲在线设备上的协战小号同步进队配合战斗，整队打完一并结算。
- 单个定时计划也可以单独指定协战小号，覆盖账号级默认搭子。

## 并发保护

同一个游戏账号同一时刻只会有一处作业运行；若该账号在其他设备上尚未跑完，新触发的作业会自动排队等候。
