## 为什么要 Root

护肝宝用 Root 读取游戏的登录信息：自动识别角色和区服、存登录快照、多账号自动切号。**只跑单个任务不需要 Root。**

## 先看你是哪种

| 你的设备 | 要做什么 |
| --- | --- |
| [模拟器](#模拟器) | 设置里开个开关，最简单 |
| [手机 · 已解锁](#手机) | 装一个 Root 管理工具 |
| [手机 · 没解锁](#手机) | 要先解锁 Bootloader，会清空数据 |

## 模拟器

在模拟器的设置里找「Root 权限」打开，重启模拟器。菜单位置随版本变化，大致在：

| 模拟器 | 在哪开 |
| --- | --- |
| MuMu | 设置中心 › 其他 › Root 权限 |
| 雷电 | 模拟器设置 › 其他设置 › ROOT 权限 |
| 其他 | 设置里搜「Root」；没有这个开关的模拟器，建议换用上面两种 |

以你所用模拟器的版本为准。

## 手机

1. 先确认 Bootloader 已解锁（各品牌方法不同，有的品牌不支持）。
2. 从下面选一个 Root 管理工具，按它官方的说明安装：
   - Magisk · [github.com/topjohnwu/Magisk](https://github.com/topjohnwu/Magisk)
   - KernelSU · [kernelsu.org](https://kernelsu.org)
   - APatch · [github.com/bmax121/APatch](https://github.com/bmax121/APatch)
3. 机型之间差别很大，这里不写具体刷机步骤，请以工具官方和你机型社区的说明为准。

## 允许护肝宝

开好 Root 后回到护肝宝，点「重新检测」→「请求权限」，在弹出的授权框里选「允许」。之前点过「拒绝」的，到 Root 管理工具的「超级用户」里把护肝宝打开。

用 KernelSU、APatch 的：这类工具不会弹授权框，直接到「超级用户」里打开护肝宝。

## 风险

:::caution[开之前请知道]
- 解锁 Bootloader 会清空手机数据，先备份。
- Root 可能影响保修；部分银行、支付类 App 会拒绝在 Root 过的手机上运行。
- 建议用一台专门挂机的手机或模拟器。
:::
