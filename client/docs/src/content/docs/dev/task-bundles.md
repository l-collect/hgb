护肝宝引擎把自动化流程与参数配置划分为清晰的四个层级，在手机端、网页控制台与开发者工作台中保持一致：

## 四层结构

1. **步骤（Step）— 配置提供者**
   步骤是一段可复用的自动化子流程（如“进入副本选层”、“切换式神录预设”）。每个步骤可以声明 `0..N` 个与自身职责直接相关的配置项（开关、单选、多选、数值等），并给出推荐默认值。
2. **任务（Task）— 配置组装与默认推荐值**
   任务按执行顺序串联若干步骤，自动把各步骤提供的配置项汇总组装成完整的参数列表，保存任务库级默认配置。用户不改任何参数也能按默认值直接运行。
3. **计划（Plan）— 启用即拷贝独立副本**
   预设计划组合了多个任务与运行时间。用户启用预设计划时，系统把任务默认配置（叠加预设微调）深拷贝到该计划名下；之后在该计划里调参只改这份独立副本，不影响其他计划与手动单跑配置。
4. **动作（Action）— 配置最终使用者**
   步骤内部的准入条件（`[条件]`）、分支走向（`按设置`）、循环次数（`最多 N 轮`）以及底层点击/输入动作读取最终生效的配置值来决定执行行为。

## 查看层级链路

在手机 App 或网页控制台打开任意任务（或计划内的某个任务），顶部提供两个标签页：

- **参数配置**：按所属步骤分组列出配置项、默认值及消费去向；
- **步骤与动作**：列出每一步是否会在当前参数下执行、提供了哪些配置项，点进单步即可查看内部每个动作如何消费这些配置。

## 版本与开源校验

任务源码采用可读的 `.hgb` 文本格式编写，打包发布在公开仓库 [l-collect/hgb-tasks](https://github.com/l-collect/hgb-tasks)，客户端与服务端按 SHA-256 摘要校验完整性。
