护肝宝账号绑定 GitHub 后即可打开网页端或手机端的**开发**工作台。

## 标准制作流程

1. **在步骤上定义配置项**：打开某个步骤（或切到“设置项”页选择提供该参数的步骤），添加开关、单选或数值字段并填好默认值。步骤只声明自己需要用到的参数。
2. **在动作里消费配置**：在步骤的流程块中使用 `[条件] 设置.xxx = true` 控制整步开关，或用 `按设置 xxx` 分支、循环次数引用该配置项。任务层会自动按步骤顺序组装出完整的配置面板。
3. **连接真机单步试跑**：选一台空闲在线手机点“试跑这一步”或“试跑整个任务”。识别框、命中坐标与候选分支会实时回传到工作台；只有拥有任务仓库写权限的维护者才能打包发布正式版本。
