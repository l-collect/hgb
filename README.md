# 护肝宝客户端与公开资源下载库（`l-collect/hgb`）

这里是 **护肝宝（HuGanBao）** 的官方安卓客户端安装包（APK）、OCR 基础识别模型资源及公开问题反馈仓库。

- **下载最新安卓客户端（APK）**：请前往右侧 **[Releases 页面](https://github.com/l-collect/hgb/releases)** 下载最新的 `hgb-x.y.z.apk`（支持 Android 11 及以上系统，ARM64 架构）。
- **查看公开透明的 `.hgb` 中文自动化脚本**：请前往任务脚本仓库 **[`l-collect/hgb-tasks`](https://github.com/l-collect/hgb-tasks)**。

---

## 功能概览：App 单机永久免费 + Cloud Pro 云端协同

### 🟢 本机免费模式（无需注册登录，安装即用）
- **15 个高内聚全玩法任务免费开放**：日常琐事、结界养成、悬赏封印、逢魔之时（含内置 1,661 题逢魔密信自动答题）、结界突破（3×3 九宫格矢量化秒扫 + 退四打九）、御魂/觉醒/御灵/契灵/英杰试炼、困28章节探索与妖气、秘闻/真蛇/六道、道馆/狩猎战/狭间/退治/宴会、版本爬塔与对弈竞猜、周三维护热更与退出。
- **游戏内悬浮球快调抽屉**：在游戏画面内随时点开悬浮球修改副本层数、挑战局数或开关项，支持「仅本次开跑」与「保存并开跑」。
- **100% 本地视觉识别与安全防封**：基于本地 ONNX OCR 与矢量化多点比色，配合设备指纹偏置截断高斯点击分布与自适应战斗巡航，不读取游戏内存、不修改游戏封包。

### 🟣 Cloud Pro 云端订阅能力（多号党与备用机/云手机神器）
- **跨设备 2人/3人同心队 & 周末协同斗技联动**：主号开房瞬间，云端自动跨设备唤醒 1～2 台协战小号手机高优插队跟车；任一账号刷完或体力耗尽，全队命运绑定同步收尾。
- **游戏分区（`clientconfig`）与登录态（`mpay`）云端 AES-GCM 加密托管与秒切**：保存账号时自动将当前分区与登录凭证加密备份至云端；多号作业执行前自动下发至目标设备秒切区服与账号，免去繁琐选区与扫码。
- **7×24 云端防封计划调度**：内置 11 套黄金作息预设计划（早间巡检、午间寄养、17:30 逢魔、19:00 寮晚间活动、20:00 多号协同寮30、周三 08:50 维护热更巡检等），支持确定性随机时间浮动（`±Jitter`）。
- **云端自进化题库与多渠道远程监控**：逢魔密信新联动题与 OCR 形近字别名全网自动收敛热更新；支持钉钉、企业微信、Bark、邮件、Webhook 告警推送及 WebRTC 浏览器直连看手机实时画面。

## 校验安装包完整性

每个 Release 版本均附带对应的 `.sha256` 校验文件，可通过以下命令核对下载的 APK 是否完整无篡改：

```bash
shasum -a 256 -c hgb-*.apk.sha256
```
