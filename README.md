# 护肝宝客户端与公开资源下载库（`l-collect/hgb`）

这里是 **护肝宝（HuGanBao）** 的官方安卓客户端安装包（APK）、OCR 基础识别模型资源及公开问题反馈仓库。

- **下载最新安卓客户端（APK）**：请前往右侧 **[Releases 页面](https://github.com/l-collect/hgb/releases)** 下载最新的 `hgb-x.y.z.apk`（支持 Android 11 及以上系统，ARM64 架构）。
- **查看公开透明的 `.hgb` 中文自动化脚本**：请前往任务脚本仓库 **[`l-collect/hgb-tasks`](https://github.com/l-collect/hgb-tasks)**。

---

## 功能概览

- **任务**：日常琐事、结界养成、悬赏封印、逢魔之时（含逢魔密信自动答题）、结界突破、御魂/觉醒/御灵/契灵/英杰试炼、困28 探索与妖气、秘闻/真蛇/六道、道馆/狩猎战/狭间/退治/宴会、版本爬塔与对弈竞猜、周三维护后更新与退出，共 15 个。
- **悬浮球**：在游戏画面里随时改副本层数、挑战局数或开关项，可「仅本次开跑」或「保存并开跑」。
- **本地识别**：用本机 OCR 和多点取色识别画面，不读游戏内存、不改封包。
- **计划**：按时间表自动开跑，内置早间巡检、午间寄养、17:30 逢魔、周三维护后巡检等预设，开跑时间可随机浮动。
- **多设备协战**：组队任务里，主号开房后自动唤醒其他设备上的小号跟车，任一账号刷完时全队一起收尾。
- **自动切号**：保存账号时把分区与登录态加密存到云端，执行别的账号的作业前自动切过去。
- **通知与远程查看**：支持钉钉、企业微信、Bark、邮件、Webhook 通知，可在浏览器里看手机实时画面。

## 校验安装包完整性

每个 Release 版本均附带对应的 `.sha256` 校验文件，可通过以下命令核对下载的 APK 是否完整无篡改：

```bash
shasum -a 256 -c hgb-*.apk.sha256
```
